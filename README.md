# Alcobot

Telegram-бот для учёта выпитого алкоголя в миллилитрах чистого этанола. Пользователь
определяется по неизменяемому Telegram ID, поэтому его статистика общая для всех чатов.

Учебная карта к прокомментированному Python-коду: [`PYTHON_GUIDE.md`](PYTHON_GUIDE.md).

## Возможности

- `/username Имя` — в любой момент изменить отображаемое имя;
- `/help` — показать описание всех команд с примерами;
- `/add напиток миллилитры` — быстро рассчитать распространённый напиток по таблице;
- `/add описание` — распознать свободное описание через `cifra48/agent`;
- `/stat` — общая сумма, средние показатели, рекордные месяц/день и стрики;
- `/history` — последние 10 записей;
- `/edit ID описание` — заново рассчитать и исправить свою запись;
- `/delete ID` — удалить свою запись;
- `/undo` — удалить последнюю запись.

Расчёт модели приблизительный и не является медицинской рекомендацией.

Шуточные фразы после добавления и поддерживающие фразы в статистике находятся в
`app/phrases.txt`. Их можно менять без правок Python-кода; новые фразы добавляются
отдельными строками в секции `[add]` и `[stat]`.

### Короткий формат `/add`

Примеры:

```text
/add beer 500
/add beer 500 4%
/add wine 12%
/add wine
/add tequila 100
/add 30
```

Поддерживаются английские и русские названия: beer/пиво, cider/сидр, wine/вино,
champagne/шампанское, vermouth/вермут, vodka/водка, whiskey/виски, rum/ром,
gin/джин, tequila/текила, cognac/коньяк, liqueur/ликёр, absinthe/абсент.

Если объём не указан, используются стандартные порции: пиво и сидр — 500 мл,
вино и похожие напитки — 150 мл, крепкий алкоголь — 50 мл. Если указано только
число, оно считается миллилитрами чистого спирта. Более сложный текст передаётся LLM.
Явно указанная крепость (`4%`, `12,5%`) имеет приоритет над табличным значением.

В свободном описании можно использовать разговорные названия и дату:

```text
/add выпил пузырь водки 24 мая
```

«Пузырь» распознаётся как бутылка; для водки без указанного объёма используется типичный
объём 500 мл. Если год не указан, выбирается ближайшая прошедшая дата с таким днём и
месяцем. Без даты запись создаётся за сегодняшний день.

Перед записью бот показывает дату, распознанные напитки, их объёмы и итоговое количество
чистого спирта. Пользователь должен нажать «Добавить» или «Отмена». Подтвердить расчёт
может только автор команды; неподтверждённый расчёт истекает через 30 минут.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Скопируйте конфигурацию:

   ```bash
   cp .env.example .env
   ```

3. Заполните в `.env` как минимум `TELEGRAM_BOT_TOKEN`, `LLM_API_KEY` и безопасный
   `POSTGRES_PASSWORD`. Пароль в `DATABASE_URL` должен совпадать с `POSTGRES_PASSWORD`.
   В `ADMIN_TELEGRAM_IDS` укажите Telegram ID администраторов через запятую.
4. Запустите:

   ```bash
   docker compose up --build -d
   docker compose logs -f bot
   ```

Таблицы PostgreSQL создаются автоматически при старте. Данные хранятся в Docker volume
`postgres_data`.

## Настройка группового чата

Добавьте бота в группу. Команды работают при включённом privacy mode, поскольку Telegram
передаёт команды ботам. Если нужно обрабатывать обычные сообщения, отключите privacy mode
через BotFather — для текущей версии это не требуется.

## Важные детали

- секреты не попадают в Git: `.env` включён в `.gitignore`;
- исходный чат хранится только для аудита и защиты от дублей;
- статистика выбирается по Telegram ID без фильтра по чату;
- профиль создаётся автоматически, а имя берётся из Telegram до выполнения `/username`;
- статистика считается за текущий календарный год с 1 января;
- среднее в месяц включает все прошедшие месяцы текущего года без записей;
- среднее в год — годовой темп, рассчитанный по текущему среднему за месяц;
- `/stat` можно выполнять как в личном диалоге, так и в группе — результат одинаков;
- скрытое поле `reasoning` из ответа API не сохраняется.

## Администрирование без перезапуска

Доступ определяется по `ADMIN_TELEGRAM_IDS` из `.env`. После первоначального назначения
администратор может менять рабочие настройки, которые сохраняются в PostgreSQL:

```text
/admin
/admin_config
/admin_set timezone Europe/Moscow
/admin_set llm_temperature 0
/admin_set llm_max_tokens 4000
/admin_set drink.beer.abv 5
/admin_set drink.beer.volume 500
/admin_unset drink.beer.abv
```

Управление статистикой:

```text
/admin_reset_user 123456789
/admin_delete_entry 42
```

`admin_reset_user` удаляет все алкогольные записи пользователя, но сохраняет его профиль
и отображаемое имя. Обычные пользователи не могут выполнять админские команды.
