# Как читать этот Python-проект после Delphi и C/C++

Рекомендуемый порядок:

1. `app/main.py` — точка входа, `async/await`, `try/finally`.
2. `app/config.py` — классы, свойства, аннотации типов и декораторы.
3. `app/drinks.py` — `dataclass`, контейнеры, comprehensions, `None`.
4. `app/statistics.py` — чистые функции, циклы, `lambda`, распаковка.
5. `app/models.py` — ORM: классы как описание таблиц PostgreSQL.
6. `app/repository.py` — транзакции и запросы к БД.
7. `app/handlers.py` — декораторы aiogram и полный сценарий команды.
8. `tests/` — небольшие примеры вызова функций и проверки результата.

## Быстрый перевод синтаксиса

| Python | Примерный аналог/смысл |
|---|---|
| `None` | `nullptr` / `nil` |
| `x is None` | проверка именно на singleton `None` |
| `str \| None` | nullable/optional строка |
| `list[T]` | динамический массив элементов `T` |
| `dict[K, V]` | hash map |
| `set[T]` | hash set уникальных значений |
| `tuple[A, B]` | фиксированная группа значений |
| `self` | `this` / `Self`, но передаётся явно |
| `@decorator` | функция, оборачивающая/регистрирующая другую функцию |
| `with` / `async with` | scoped resource management, близко к RAII |
| `yield` | генератор, выдающий значения по требованию |
| `await` | неблокирующее ожидание coroutine |
| `[f(x) for x in items]` | построение списка циклом |
| `f"{value:.2f}"` | форматированная строка |
| `*args`, `**kwargs` | переменные позиционные и именованные аргументы |

## Важные отличия

- Отступы являются частью синтаксиса. Фигурных скобок для блоков нет.
- Аннотации типов в основном помогают IDE, линтеру и человеку; Python обычно не
  запрещает передать значение другого типа во время выполнения.
- Переменная хранит ссылку на объект, а не объявленную область памяти конкретного
  типа. Простое присваивание списка не копирует список.
- `==` сравнивает значения, `is` — идентичность объектов. Для `None` используется
  `is None`.
- Пустые строки и контейнеры, число `0` и `None` считаются false в условиях.
- Исключения используются активнее, чем коды возврата. Внешние ошибки обычно
  преобразуются в понятные исключения предметной области.
- Для денежных и точных дробных величин здесь используется `Decimal`, потому что
  обычный `float` имеет двоичную погрешность, как `double` в C++.

## Небольшие упражнения

1. Добавьте напиток в `DRINKS` и тест для него.
2. Добавьте в статистику среднее количество спирта на один день употребления.
3. Добавьте новую секцию в `phrases.txt` и функцию, выбирающую фразу из неё.
4. Напишите тест для `_parse_volume("0")` и объясните, почему результат — `None`.
5. Перепишите один list comprehension обычным циклом `for`, затем сравните версии.
